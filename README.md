# Projeto Web

## Sobre o projeto

Este projeto foi desenvolvido durante a disciplina de Experiência Prática. O objetivo é criar um site com uma estrutura organizada, acessível e responsiva, utilizando boas práticas de desenvolvimento web.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Funcionalidades

* Navegação entre as páginas/seções do projeto
* Menu responsivo com menu hamburger
* Projetos apresentados em cards
* Modal para apresentação dos projetos
* Formulário de cadastro
* Validação dos campos do formulário
* Armazenamento dos cadastros utilizando `localStorage`
* Recuperação dos dados após atualizar a página

## Estrutura do projeto

## Pré-requisitos

Para executar o projeto é necessário ter:

* Um navegador atualizado, como Google Chrome, Microsoft Edge ou Firefox.
* Visual Studio Code ou outro editor de código, caso seja necessário alterar os arquivos.
* Git, caso seja necessário clonar o repositório.

## Instalação

O projeto não possui dependências externas que precisem ser instaladas.

Para utilizar o projeto:

1. Clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize uma extensão como o Live Server.

## Execução

O projeto pode ser executado diretamente pelo arquivo `index.html`.

Também é possível utilizar o **Live Server** no Visual Studio Code para executar o projeto localmente.

## Build

Por ser um projeto desenvolvido com HTML, CSS e JavaScript puro, não é necessário executar um processo de build ou utilizar um gerenciador de pacotes.

Os arquivos podem ser utilizados diretamente no navegador.

## Testes

Foram realizados testes manuais no navegador para verificar:

* Funcionamento da navegação.
* Funcionamento do formulário.
* Validação dos campos.
* Abertura e fechamento dos modais.
* Armazenamento dos cadastros.
* Recuperação dos dados após atualizar a página.
* Responsividade da interface.
