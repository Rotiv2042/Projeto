# Projeto

Projeto desenvolvido durante a disciplina de Experiência Prática.

## Sobre o projeto

Este projeto consiste em um site desenvolvido com HTML, CSS e JavaScript,
com foco em organização, responsividade, acessibilidade e boas práticas
de desenvolvimento web.

## Objetivo

O objetivo do projeto é aplicar conhecimentos de desenvolvimento web,
versionamento de código e organização de um projeto utilizando Git e GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Navegação entre as páginas/seções do site
- Menu responsivo
- Formulário de cadastro
- Validação dos campos
- Armazenamento de dados utilizando localStorage
- Exibição dos cadastros realizados
- Modal para informações dos projetos
- Cards de projetos
